## 短板和不该买的人

**1000Mbps 双 ISP 国际带宽那两款，官网自己写了“网络质量较差，建议中转优化”。** 这是官方原文，不是别人黑它。意思是这条线适合做落地节点，前面挂个中转再用；想拿它当主力直连，晚高峰会难受。它便宜是有原因的。

**“原生 IP”不等于“住宅 IP”。** 官网在双向 4837 优化系列的说明里写得很直白：提供美国机房 IP，非 ISP 住宅 IP。整张表里，只有 AT&T 那款和几个标了“双 ISP”的系列明示了 ISP 属性，CN2 GIA 系列官网明确写“不保证 ISP 属性”。如果你的业务对 IP 归属地敏感，别看着“原生”两个字就下单，先看清楚哪一款写了 ISP。

**最高配置只有 2 核 2G。** 跑个博客、做代理、挂个小服务没问题，编译大项目、跑数据库、开多个容器就吃力了。需要 4 核以上的，这家不是合适的选择。

**AT&T 那款经常缺货。** 官网直接写“本次到货仅 50 个”，卖完就没了，价格还是 200 元/月。冲着家宽 IP 来的，得接受等补货这件事。

**只想要几美元级别的低价机，别在这看。** RackNerd 这类主打低价的商家，一年十几美元的套餐常年有，配置和线路是另一套逻辑。六六云 45 元/月起步，买的是洛杉矶原生 IP 和 CN2 GIA 这类线路，不是单纯的便宜。

## 常见问题

### 六六云支持支付宝吗？

支持。官网和第三方整理都把支付宝列为付款方式，结账时选支付宝扫码付款即可，不用信用卡，也不用 PayPal。

### 45 元那档和 200 元的 AT&T 差在哪？

差在 IP 属性和产品定位。AT&T 卖的是美国家宽 IP，200Mbps 带宽、2TB 流量、20GB 系统盘，200 元/月，官网标“本次到货仅 50 个”，当前缺货。45 到 50 元那档是普通美国机房 IP，1000Mbps 带宽、1TB 流量，走的是大带宽路线。买 AT&T 买的是 IP 归属，不是配置。

### 能解锁 TikTok、ChatGPT、Netflix 吗？

官网只在 CN2 GIA 系列上明写“支持 tiktok、chatgpt，解锁 netflix”，前提是全新 IP 段。其他系列的措辞是“助力 tiktok 业务”或“谷歌防送中”，没有对 Netflix 做承诺。解锁这件事和 IP 段关系很大，同一个系列换一批 IP 结果都可能不一样。

### 退款怎么算？

常规产品支持开通后 48 小时内退款。限定词是“常规产品”，下单前最好确认你要买的那款算不算在内。48 小时这个窗口比不少商家的 7 天短，但它至少把政策写出来了，不像有些商家干脆写不退款。

### 美国VPS用支付宝付款还有哪些商家？

VMISS 是加拿大公司，加元结算，也支持支付宝；VIRCS 主打加州真实住宅 IP，明确不支持任何理由退款，也不允许建站；此外 DMIT、恒创科技、RackNerd、Hosteons 都支持支付宝。这几家我没有逐个核官网，只作为名字给你一个继续查的方向。
